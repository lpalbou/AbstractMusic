# Code Of Conduct

This project follows a simple contributor standard: be respectful, stay technical, and keep
discussion focused on improving the software.

## Expected Behavior

- Use welcoming and professional language.
- Give and receive technical criticism constructively.
- Respect maintainer decisions about scope, dependencies, licensing, and safety boundaries.
- Report security concerns through [SECURITY.md](SECURITY.md), not public issues.

## Unacceptable Behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private information without permission.
- Repeatedly derailing technical discussions after a maintainer asks to stop.

Maintainers may moderate issues, pull requests, discussions, and project spaces to preserve a
productive environment.
